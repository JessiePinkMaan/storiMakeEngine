StoriMakeEngine
Консольный движок для текстовых интерактивных историй на C++.

Описание
StoriMakeEngine — это небольшой C++ фреймворк для создания визуальных новелл и текстовых приключений прямо в консоли. Движок позволяет писать разветвлённые диалоги с персонажами, паузами, анимированным выводом текста и выбором игрока, влияющим на развитие сюжета.

Структура
Persona — персонаж с именем, репутацией и методами вывода реплик (Say, SayInline)
DialogLine — одна реплика: персонаж, текст, режим вывода
Action / ActionType — действие в сцене: пауза, ожидание ввода, выбор, реплика
StoryBlock — блок истории: набор реплик и действий, поддержка ветвления через AddChoice
Choice — ввод выбора игроком из нескольких вариантов
Scene — воспроизводит StoryBlock, рекурсивно обрабатывает ветви выбора
ExitBlock / BlockResult — управление переходами между сценами

Возможности

Диалоги с несколькими персонажами
Ветвление сюжета через выбор игрока
Паузы между репликами (timeOut)
Ожидание нажатия пробела (waiteForPress)
Инлайн-вывод текста (для эффекта набора)
Система репутации персонажей (заготовка)
Поддержка переходов между сценами (в разработке)
